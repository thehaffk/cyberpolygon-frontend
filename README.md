# CyberPolygon Frontend

Фронтенд для образовательной платформы CyberPolygon, созданной для обучения кибербезопасности через практические задания и интерактивные курсы.

## Реализованный функционал

### ✅ Страницы:
- Главная (`/`)
- Профиль пользователя (`/profile`)
- Курсы (`/courses` + `/courses/:slug`)
- Задания (`/tasks` + `/tasks/:id`)
- Терминал для практики (`/terminal`)
- Тесты знаний (`/tests` + `/tests/:id`)
- Авторизация (`/login`, `/register`)
- Страница 404 (`*`)

### ✅ Авторизация:
- Токен хранится в `localStorage`
- Axios добавляет `Authorization` заголовок
- Защищенные маршруты через `PrivateRoute`
- Перенаправление на `/login` при отсутствии токена

### ✅ Курсы:
- Отображение списка курсов с фильтрацией
- Детальная страница курса с уроками
- Отображение markdown контента через `react-markdown`
- Индикаторы сложности и категорий курса

### ✅ Тесты:
- Вопросы с одним или несколькими вариантами ответов
- Таймер для ограничения времени прохождения
- Подсчет результатов и отображение статистики
- Сохранение пройденных тестов в профиле

### ✅ Терминал:
- Интеграция с `xterm.js`
- WebSocket соединение для передачи команд
- Аутентификация через JWT токен

### ✅ Задания:
- Фильтрация и поиск по категориям и уровню сложности
- Форма для отправки найденных флагов
- Подробное описание заданий с подсказками

### ✅ Дизайн:
- Неоновая темная тема с акцентами
- Адаптивная верстка для всех устройств
- Анимации и переходы для улучшения UX

## Запуск проекта

### Разработка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start
```

Приложение запустится на http://localhost:3000

### Сборка и деплой

```bash
# Создание оптимизированной сборки
npm run build

# Запуск собранной версии
npm install -g serve
serve -s build
```

## Конфигурация

Backend API должен быть доступен по адресу, указанному в proxy в package.json:

```json
{
  "proxy": "http://localhost:8000"
}
```

## Структура проекта

```
frontend/
├── public/              # Статические файлы
├── src/
│   ├── api/             # API клиенты и axiosInstance
│   ├── components/      # React компоненты
│   │   ├── layout/      # Компоненты макета (Navbar, Footer)
│   │   └── ...          # Другие компоненты
│   ├── pages/           # Страницы приложения
│   ├── services/        # Сервисы (WebSocket, queryClient)
│   ├── store/           # Redux store
│   │   └── slices/      # Redux slices
│   ├── App.jsx          # Основной компонент с маршрутизацией
│   ├── index.tsx        # Точка входа
│   ├── theme.ts         # Тема MUI
│   └── index.css        # Глобальные стили
└── package.json         # Зависимости
```
